### 3. Bug 修复

**问题**: 空文件测试失败  
**原因**: 空文件时 `lines.length` 为 0，但代码未正确处理这种情况  
**修复**: 添加空文件检测逻辑，返回 null

```typescript
// Handle empty files
if (lines.length === 0 || (lines.length === 1 && lines[0] === '')) {
  return null;
}
```
