- **正式名称**: ErrorPare


#### Logo含义

- **E**: Error（错误）
- **P**: Pare（削减、压缩）
- 颜色组合：深蓝底 + 青/绿渐变 = 科技感 + 效率

## 📝 文案风格

### TONE原则

- **专业** - 但不冷冰冰
- **简洁** - 去掉废话
- **友好** - 像朋友帮助
- **自信** - 不吹牛，实事求是

### 常用短语

| 中文 | 英文 |
|-----|------|
| 快速开始 | Quick Start |
| 立即体验 | Try Now |
| 免费使用 | Free to Use |
| 了解更多 | Learn More |
| 开始使用 | Get Started |
| 提交反馈 | Give Feedback |

### 禁用语

- ❌ "最好的"（除非有数据支持）
- ❌ "革命性的"
- ❌ "颠覆性的"
- ❌ "无敌的"
- ❌ "100%完美"
