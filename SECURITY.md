# Security Policy

## Supported versions

Security fixes are applied to the latest released version on the default branch.

At the moment, the supported release line is:

- `2.1.x`

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Instead, send a private report to [security@errorpare.dev](mailto:security@errorpare.dev) with:

- a description of the issue
- impact and affected surfaces
- reproduction steps or proof of concept
- any suggested mitigation, if you have one

We will aim to:

- acknowledge receipt within 5 business days
- confirm severity and next steps after triage
- coordinate a fix and release before public disclosure when possible

If the report involves credentials, API keys, or private customer data, please redact anything sensitive before sending it.
